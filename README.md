# 7 Days to Automate - Releases

Downloads for **7 Days to Automate** (7D2A), a 7 Days to Die mod by Shavick that adds item, liquid and gas pipes, valves, machines, power, networked storage, and a virtual horde system.

## Install

1. Download the latest `7DaysToAutomate-vX.Y.Z.zip` from [Releases](https://github.com/Shavick/7DaysToAutomate-Releases/releases).
2. Extract it so you have a `7DaysToAutomate` folder.
3. Put that folder in `%APPDATA%\7DaysToDie\Mods\` (create `Mods` if it doesn't exist). For a dedicated server, put it in the server's `Mods` folder.
4. Fully restart the game. Mods only load at startup.

Built for 7 Days to Die V3.4. EAC must be off.
